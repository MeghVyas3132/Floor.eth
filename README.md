# Floor

Effective-state security ratings for onchain collateral, with bounded enforcement.

> "Kelp's attacked bridge route had one checker for 12.5 months. Every lender accepted rsETH anyway."

Floor continuously grades who or what can release a collateral asset, how many independent parties must agree, and how fast those settings can change. It encodes Aave's DAO-approved risk framework as code, and lets lenders act on the grade automatically, without ever moving funds or blocking repayments or liquidations. Every grade carries its evidence, and anyone can re-verify it in a browser without trusting Floor.

**Live: https://floor.aexiz.in** · landing, [Live market](https://floor.aexiz.in/#/live) (every Aave V3 market, read in your browser), [Kelp simulation](https://floor.aexiz.in/#/kelp), [verify a rating](https://floor.aexiz.in/verify/) and the [bridge dataset](https://floor.aexiz.in/verify/dataset.html). The same build is on Swarm: https://bah5acgzaf2sbw664j66ntj5gz4kttvnviv5i3mfvdtthz5b3izltcslqbkhq.bzz.limo/ (republished on every deploy). Everything that writes runs on testnets; mainnet is only read. No real funds.

Built at ETHGlobal Mumbai (Nov 5–7 2026). Docs: [`docs/README.md`](docs/README.md). Agent rules: [`AGENTS.md`](AGENTS.md). AI disclosure: [`AI-USAGE.md`](AI-USAGE.md).

## How it works

```
resolver (pinned block, 3 RPCs)  ->  evidence bundle  ->  Swarm (bytes)  +  Arkiv (floor.rating / floor.route)
        |                                   |
        v                                   v
   CRE feed  ->  CRE workflow: re-reads the evidence at the pinned block on every node, checks a lower-bound grade
                  -> signed report -> FloorRegistry  -> FloorBroadcaster --CCIP 2.0--> FloorMirror (2nd chain)
                                            |
                          FloorSentinel (Morpho V2 caps)  /  AaveFreezeEnforcer (freeze)
browser verifier: Arkiv -> Swarm -> hash check -> replay every read via Anon-RPC -> re-run rules -> VERIFIED

live market (browser, every 60 s): all 24 Aave V3 markets -> collateral, supply, oracle price, LayerZero bridge kind
scheduler (GitHub Actions): watch.yml every 15 min (LayerZero config events on every chain with an Aave market),
                            probe.yml hourly, deploy.yml -> GitHub Pages (floor.aexiz.in) + Swarm
```

## Headline results (all reproducible)

- **Kelp replay (mainnet fork, the attacker's real transactions):** without Floor the attacker borrows; with Floor the real supply tx reverts with Aave `ReserveFrozen()` and **$0 is borrowed on Aave**. After the freeze, **repay and liquidation still work**. `contracts/test/fork/KelpReplay.t.sol`
- **rsETH the day before the hack (block 24,908,284):** BREACHED. 24 of 26 inbound routes resolve to one effective verifier; 25 of 26 receive libraries were unpinned; controlled by a 3-of-6 Safe with no timelock. `packages/resolver/fixtures/rseth-24908284.json`
- **Inbound limits, 64 LayerZero adapters over Aave-listed tokens on 8 chains (2026-11-07):** 31 release their full escrow, or mint without a cap, on one inbound message; 4 are inbound rate-limited (EtherFi weETH, PYUSD `0xa2c3`, USDG `0x147b` on Ethereum, USDG on Ink); 8 undetermined (custom codecs / empty escrow); 21 inactive or LayerZero v1. Every decisive result cross-checked on a second RPC. `docs/09`, `docs/evidence/inbound/`
- **Real Morpho Vault V2 (Base fork):** a BREACHED rating makes FloorSentinel cut the collateral cap to 0; the sentinel cannot raise caps. `contracts/test/fork/MorphoBaseFork.t.sol`
- **CCIP 2.0, live:** the CRE-written rating went from Ethereum Sepolia to Base Sepolia over CCIP (send `0xd1b846b6…cd3e`, delivered 17.7 min later in `0xe8994fb0…cdf9`); the sentinel on Base then cut a real Morpho Vault V2 cap to 0 (`0x2e02faf9…7908`). Fork-tested on the real lanes with chainlink-local: `contracts/test/fork/CCIPToBaseEnforcementFork.t.sol` (6 tests, incl. an untrusted sender rejected on Base).
- **CRE refuses lies:** fed a feed claiming rsETH is OK, every node re-reads the chain and the workflow outputs REJECT ("feed understates risk"); with forged evidence too, REJECT ("read c505 mismatch"). `docs/evidence/cre/lies-2026-11-07.txt`
- **CRE reacts to the transaction that set up the hack:** a log trigger on LayerZero's `UlnConfigSet`, simulated on Kelp's real Apr 2 2025 tx: the handler re-reads the route at block 22,179,964 and writes BREACHED. `docs/evidence/cre/event-trigger-2026-11-07.txt`
- **CRE:** the workflow passes `cre workflow simulate` (CRE CLI v1.39.0): fetches the feed, re-reads the evidence on Ethereum mainnet at the pinned block, 4/4 reads match. `docs/evidence/cre/simulate-2026-11-06.txt`
- **Anon-RPC, on the live deployment:** in Chrome, the verify page finds the rating on Arkiv, downloads the bundle from Swarm, checks the hash against Arkiv and the CRE-written registry, then re-checks all 624 reads over **Tor (tor-js): VERIFIED in 50–81 s** (Nym mixnet: 70–103 s); **99.7–99.8% of requests through Anon-RPC** (the other 2 are the harness's bootstrap read, by design). One flipped byte gives MISMATCH. `docs/evidence/anon-rpc/2026-11-06-browser-runs.md`, `docs/evidence/live-2026-11-07.md`
- **Live market:** every Aave V3 market (24) read from its own chain by the browser every minute: which reserves are collateral (incl. E-mode only), supply, oracle price, and which are LayerZero OFTs or home-chain adapters, classified with the inbound probe. Bridge config changes are watched every 15 minutes and shown on the same page. `packages/live`, `apps/web/src/screens/LiveMarket.tsx`

## CROPS

- **C (censorship resistant):** checking a grade needs no Floor server. The evidence bundle is on Swarm, its hash is on Arkiv and in the CRE report onchain, and every chain read goes through Anon-RPC and rotates across several RPC providers, any of which you can swap in the page. The rating is also mirrored to a second chain over CCIP. The whole site is published to Swarm on every deploy. *Limits today:* the default RPCs are free public endpoints; the tor-js gateways are temporary and run by others (production needs its own); each deploy gives a new Swarm reference (no feed manifest yet, so there is no single stable Swarm URL).
- **O (open source):** Apache-2.0. All code, the rule pack, the evidence bundles, the importer and every test are in this repo; anyone can re-run the resolver at the same block and get the same bytes.
- **P (private):** the browser verifier routes the Arkiv lookup, the Swarm download and every chain read through EF Anon-RPC (Tor by default; Nym selectable, but Nym drops the Content-Type header so the Arkiv lookup then goes direct, shown on the meter). Measured share: 99.7–99.8% of requests; the 2 direct reads are the harness reading the specifier contract before the anonymised fetch exists, which only reveals that Anon-RPC is in use. No trackers, analytics or third-party scripts. The verify and dataset pages bundle their fonts; the landing and app pages still load their fonts from Google Fonts, which sees the visitor's IP (to be self-hosted). *Limits:* RPC providers still see the queries (not who sent them); "passthrough" mode exists for testing and is labelled not anonymous.
- **S (secure):** the verifier trusts nothing from Floor: hash check, byte-for-byte replay of every read, decoded-state check and grade recomputation. Any failure ends MISMATCH or UNVERIFIED_RPC, never VERIFIED (tests). Anon-RPC worker bundles are hash-pinned onchain and run sandboxed. Enforcement contracts can only reduce risk (invariant tests). *Not yet audited.* *Testnet limit:* the CRE **simulation** forwarder on Sepolia checks no signatures, so anyone can push a report into our Sepolia registry through it (asserted in `contracts/test/fork/CreForwarderSepolia.t.sol`); the registry's newer-scan-only rule makes replays harmless, and the sentinel can only lower caps. Production uses Chainlink's KeystoneForwarder, which verifies the DON's signatures, plus the registry's workflow owner/name check.

Run the verifier: https://floor.aexiz.in/verify/, or locally `pnpm --filter @floor/verify-lab dev` → http://127.0.0.1:5181 (see `apps/verify-lab/README.md`). Build the whole site: `scripts/build-site.sh`; check the live deployment end to end: `scripts/check-live.sh`.

## Arkiv queries (all filtered by the writer as creator)

```ts
// the Mirror-track query: every adapter backing Aave collateral that can release everything in one message
client.select().from(FloorAdapter).where(eq("outcome", "NO_INBOUND_LIMIT")).createdBy(writer).orderBy(desc("routes")).fetch()
// the flight recorder: rsETH's sourced bridge history, oldest first
client.select().from(FloorEvent).where(eq("token", addr(rsETH))).createdBy(writer).orderBy(asc("block")).fetch()
// a rating and its routes
client.select().from(FloorRating).where(eq("token", addr(rsETH))).createdBy(writer).orderBy(desc("block")).fetch()
```
